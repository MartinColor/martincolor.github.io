# Cómo armar un presupuesto rápido

Matías te pide algo así: «Haceme un presupuesto de 1 L de fondo, 1 L de barniz y 1 kg de masilla para 3 piezas».
O más corto: «presupuesto paragolpe, guardabarro y capot, gris metalizado».

## Pasos
1. **Entendé el pedido.** Si falta algo importante, preguntá **una sola cosa por vez**:
   - ¿Cuántas piezas? (o cuáles)
   - ¿Color liso o metalizado? (para saber si va base poliéster + barniz o poliuretano)
   - ¿Tiene golpes? (si no tiene, no lleva masilla)
   Si él ya dijo las cantidades, **usá las de él**, no las cambies.
2. **Sacá las cantidades** con `equivalencias.md`.
3. **Buscá los precios en Infogestión** (solo mirar, no tocar nada):
   - Buscá cada producto por **código** (ver lista abajo) o por nombre.
   - Usá el **precio de venta con IVA**.
   - Si un producto **no tiene stock**, avisá: «Bo, de esto no hay stock».
   - Si no podés entrar a Infogestión o no encontrás un producto, pedile a Matías que te dicte el precio. **Nunca inventes un precio.**
   - Anotá los precios que encontraste en `precios-guardados.md` con la fecha. Si un precio guardado tiene más de 7 días, volvé a buscarlo.
4. **Hacé la cuenta:** cantidad × precio de cada cosa, y el total. Revisá la suma dos veces.
5. **Mostrale el presupuesto** con este formato, listo para copiar y mandar por WhatsApp o imprimir:

```
*Martín Color · Presupuesto*
Cliente: [nombre, si lo dijo]
Trabajo: [paragolpe, guardabarro y capot] – [base poliéster + barniz]

• 1 L Fondo P41.04 → $ ...
• 1 Catalizador fondo ND010.16 → $ ...
• 800 g Base poliéster color [color] → $ ...
• 1 L Barniz B21.11 → $ ...
• ½ L Catalizador barniz 010.021 → $ ...
• 1 kg Masilla Sprint → $ ...
• Lijas: 3 de 80, 150, 240, 320, 600 y 800 → $ ...
• 1 L Diluyente → $ ...

*TOTAL: $ ...*
Precios con IVA. Válido por 7 días.
Cantidades aproximadas; pueden variar según el estado de las piezas.
```

6. **Guardalo** en la carpeta `presupuestos/` con el nombre `AAAA-MM-DD cliente.md` (si no hay nombre, poné la hora).
7. Cerrá con una línea para Matías: «Ta bo, ahí está. Si querés te lo paso para mandárselo al cliente por WhatsApp.»

## Códigos de los productos
| Producto | Código |
|---|---|
| Barniz 2K | B21.11 |
| Catalizador de barniz | 010.021 |
| Fondo relleno | P41.04 |
| Catalizador de fondo | ND010.16 (Martín no está seguro: confirmar) |
| Masilla Sprint 1 kg | — buscar por nombre |
| Base poliéster | se prepara por peso según el color |
| Poliuretano | se prepara según el color |
| Epoxi F351 | F351 |
| Lijas | buscar por grano (80, 150, 240, 320, 600, 800, 1000) |
| Diluyente | buscar «diluyente» |

Si un código no aparece en Infogestión, avisá a Matías para que le diga a Martín y se corrija acá.
